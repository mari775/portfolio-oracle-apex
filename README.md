# Portfólio Oracle APEX

Aplicação desenvolvida em Oracle APEX como parte do meu portfólio profissional.

## Sobre o projeto
Este projeto apresenta meu portfólio pessoal, com informações sobre formação, tecnologias, projetos e contato.

## Páginas da aplicação
- Sobre mim
- Formação
- Tecnologias
- Projetos
- Participações
- Contato

## Tecnologias utilizadas
- Oracle APEX
- SQL
- PL/SQL

## Como executar
Para executar o projeto, importe o arquivo `.sql` em um ambiente Oracle APEX.

## Observação
Projeto desenvolvido para fins de estudo e portfólio.
